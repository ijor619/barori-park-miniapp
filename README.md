# Барори Парк — Telegram Mini App v1.3

Демонстрационный личный кабинет курьера для тестового бота `@TestParkIgor_bot`.

## Что работает

- четыре раздела: главная, заказы, бонусы и профиль;
- переключение статистики за день, неделю и месяц;
- карточки тестовых заказов и модальные окна;
- настройки демо-уведомлений и темы;
- расчёт кэшбэка от комиссионной базы по подтверждённым месячным уровням;
- интеграция с Telegram Web Apps SDK (`ready`, `expand`, тема, BackButton, haptic feedback).

## Безопасность данных

Проект содержит только вымышленные демонстрационные сведения. В нём нет токена бота, API-ключей, реальных ФИО, телефонов, адресов, маршрутов или данных CRM. Для настоящих данных потребуется отдельный защищённый сервер: доверять `initDataUnsafe` на клиенте нельзя, а `initData` следует проверять на серверной стороне.

## Локальный запуск

Это статическое приложение без сборки. Откройте `index.html` либо запустите любой локальный HTTP-сервер из корня проекта.

## Публикация

В репозитории откройте **Settings → Pages** и в блоке **Build and deployment** выберите:

- **Source:** `Deploy from a branch`;
- **Branch:** `main`;
- **Folder:** `/ (root)`;
- затем нажмите **Save**.

После первого развёртывания адрес будет таким:

`https://ijor619.github.io/barori-park-miniapp/`

## Подключение к BotFather

1. Откройте официальный бот `@BotFather` в Telegram.
2. Отправьте команду `/setmenubutton`.
3. Выберите `@TestParkIgor_bot`.
4. Если BotFather показывает дополнительное меню, выберите настройку кнопки меню (`Configure menu button`).
5. В ответ на запрос URL отправьте `https://ijor619.github.io/barori-park-miniapp/`.
6. В ответ на запрос названия кнопки отправьте `Личный кабинет`.
7. Дождитесь подтверждения BotFather, затем заново откройте чат с тестовым ботом и нажмите кнопку меню.

Токен бота для этой настройки не требуется. Не отправляйте его в репозиторий или переписку.
